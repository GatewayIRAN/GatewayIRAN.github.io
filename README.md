# GatewayIRAN.github.io

This repository builds and serves the [GatewayIRAN website](https://gatewayiran.github.io),
the public landing page for the collection around **`certway`** — the one-binary
ACME client that gets a TLS certificate from Let's Encrypt (or any ACME server)
onto Linux or macOS and keeps it renewed.

- The site is rendered with GitHub Pages directly off the `main` branch (no build step).
- The project behind it is [certway](https://github.com/GatewayIRAN/certway).
- The community lives on the [Telegram channel](https://t.me/GatewayIRAN).

If you arrived here looking for the tool itself, go to
**[certway](https://github.com/GatewayIRAN/certway)** — or follow
**[the channel](https://t.me/GatewayIRAN)** for releases, how-tos and comparisons.

GatewayIRAN — certway · MIT · built on `ring` and `rustls`
